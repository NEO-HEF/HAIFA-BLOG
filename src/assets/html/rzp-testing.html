5. Doporučený další krok

Stále 1 scénářů nemá ani skeleton. Spusť skript s -MaxScaffolds 3 (nebo více) k postupnému doplnění.
Pro implementaci skeleton testu:
  1. Otevři soubor uvedený ve sloupci „Test class" (např. OwnerSelectionCancelE2ETests.cs).
  2. Sleduj implementační poznámky v hlavičce souboru.
  3. Přidej host mód do Fenix.RZP.WinForms/E2E*Runner.cs + dispatch v Program.cs.
  4. Naplň tělo testu (vzor: OwnerSelectionE2ETests.cs).
  5. Odeber atribut [Fact(Skip="…")] → přepni na [Fact].
  6. Spusť skript znovu — report se aktualizuje, pokrytí se posune nahoru.

6. Reprodukovatelnost

Tento běh:

pwsh -NoProfile -File scripts/testing/run-rzp-full-qa-auto.ps1 -MaxScaffolds 0

Vstupy:

  • Katalog: docs/implementation-results/RZP/qa/e2e-catalog.csv
  • Template: scripts/testing/templates/e2e-skeleton.cs.template
  • Unit test project: src/modules/RZP/Fenix.RZP.Tests/Fenix.RZP.Tests.csproj
  • E2E test project: src/modules/RZP/Fenix.RZP.E2E.Tests/Fenix.RZP.E2E.Tests.csproj

Bezpečné parametry pro různé situace:

  • -MaxScaffolds 0 — jen report, nic negeneruje
  • -SkipUnitTests — přeskočí unit/integration vrstvu
  • -SkipE2ETests — přeskočí E2E (pokud GUI session není dostupná)
  • -OpenReport — otevře HTML v defaultním prohlížeči

Automatický QA report pro modul RZP. Limit scaffold/run zajišťuje, že běh neexploduje (žádná smyčka).

Pro další scénáře přidej řádek do e2e-catalog.csv a spusť skript znovu.
